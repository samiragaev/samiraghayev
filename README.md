# Samir Aghayev — resume website

Static, dark-mode resume page. No build step: open `index.html` in a browser.

- `index.html` — the page
- `photo.jpg` — profile photo
- `Samir_Aghayev_CV.pdf` — downloadable CV

Live at https://samiragaev.com (GitHub Pages with a custom domain, see `CNAME`).

## App icons

Each app card looks for `icons/<slug>.png` (square, ~128×128) and shows
the app's initials until the file exists. Slugs: irshad, ofisait, etta,
emin-bazar, paypark, mybanko, norm-bonus, norm-ustalar, fayton-user,
fayton-driver, azerishiq, ebina, ebina-manager, unimastery, yeniavaz, agro.

## Language

The page is bilingual (EN/AZ). `?lang=az` opens it in Azerbaijani; the
visitor's choice is remembered in the browser.
