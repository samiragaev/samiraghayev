Open source

dio_debug_logger

v0.4.0 · MIT

An in-app network inspector for Dio, published on pub.dev. Two lines to set up, and automatically disabled in release builds.

Dio üçün tətbiq daxilində şəbəkə inspektoru, pub.dev-də dərc olunub. Qoşulması iki sətirdir, release build-lərdə avtomatik söndürülür.

  • Draggable debug button that opens a searchable request log with request, response and error details.
  • Statistics, retry, and export as cURL, Postman or JSON.
  • Passwords, tokens and keys masked everywhere: UI, console, copy and export.
  • Switch between dev, staging and prod backends at runtime.
  • Sürüklənən debug düyməsi: axtarışlı sorğu siyahısı, sorğu, cavab və xəta detalları.
  • Statistika, sorğunu təkrarlamaq, cURL, Postman və ya JSON kimi ixrac.
  • Parol, token və açarlar hər yerdə gizlədilir: interfeys, konsol, kopyalama və ixrac.
  • İş zamanı dev, staging və prod serverləri arasında keçid.
